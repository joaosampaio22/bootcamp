Experimente com dados fictícios

Depois de instalar Node e Docker, siga o README: prepare o ambiente, execute npm run demo:setup e npm run demo. O acesso é gerado somente no seu computador. A demo usa banco, cookie e chave separados.

O que está pronto

Cadastro/login, disciplinas livres, foco com pausa e recuperação, conteúdos, revisões por autoavaliação, pontos de retorno, Academia Viva e estatísticas. Dados persistem em PostgreSQL e as recompensas são transacionais e idempotentes.
