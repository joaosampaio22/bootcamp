# Evidências reais do desenvolvimento com IA

Esta pasta começa vazia de evidências. Quando o Codex for usado para desenvolver o app, inserir registros **verdadeiros** de prompts, decisões, capturas sem dados sensíveis, diffs e testes executados. **Não fabricar transcrições ou testes.**

Modelo de registro: data, etapa, RF/RN/CA, prompt utilizado, decisão humana, arquivos modificados, comando executado, saída resumida, captura (quando existir), limitação.
